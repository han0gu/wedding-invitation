## 청첩장 개발 및 운영

- 소스 코드는 Public GitHub repository(https://github.com/han0gu/wedding-invitation)로 관리한다.
- 하객들에게 `https://invitation.soowa.site`로 제공한다. 
- `soowa.site` 도메인은 이미 구매해두었다.
    - 1차 ns: `ns.gabia.co.kr`
    - 2차 ns: `ns1.gabia.co.kr`
    - 3차 ns: `ns.gabia.net`
- PC 브라우저에서 접속한 경우에도 모바일 브라우저에서 접속한 것과 동일한 UI를 제공한다.
