> **For agentic workers:** Use superpowers:executing-plans for main implementation. Asset-only subagents are prescribed by image-to-code.

**Goal:** Faithful local mobile wedding invitation from the provided video.
**Architecture:** React web page, generated raster decorations, canvas curtain and CSS gates. Static frontend; no backend.
**Tech Stack:** React, Vite, CSS, Canvas 2D, Node built-in tests.
**Spec:** ../specs/261018-113000-invitation-design.md

## Global constraints
- Mobile web with no phone frame. English sample content, blush/olive illustrated palette.
- Never alter user's existing docs or runs. Art generated in public/assets. No external deployment.
- Browser-rendered checks required; record limitations honestly.

## Review focus
- Image loading failure must not lock page.
- Reduced motion must reveal content without animation wait.
- Replay/skip must reset or release scrolling and allow keyboard access.
- Small/landscape viewports must not clip horizontal content.
- Date/calendar content must agree and countdown must never become negative.
