# Artwork and fonts

All illustrated artwork below was generated with the built-in imagegen tool using extracted frames from the user's supplied video as visual references. Each result was inspected. Alpha transparency is preserved where applicable. Optimized WebP files are served; PNG masters are retained under `../outputs/invitation-analysis/generated-originals/` after final packaging.

## Prompt set

- **estate:** Flat front-on portrait French wedding illustration. Pale blush paper upper field; lower scene with symmetrical rose-colored two-storey manor, black shutters, terracotta roof, purple wisteria, narrow cypress, clipped olive hedges, mint oval fountain and foreground ivory/dusty rose blooms. Fine engraved watercolor cut-paper style. No device, hands, text or curtains. Reference frame 8s.
- **curtain:** Fully closed symmetrical blush rococo curtain. Exactly three scalloped swags at top 20–22%, pearl tassel trim, narrow vertical pleats below, centered seam, textile edge to edge. Fine embossed engraved stationery style. No scenery or words. Reference frame 4s.
- **open-curtain:** Edit closed curtain to open tied-back side panels with curved pearl-lined edges, wide transparent center; preserve material and triple top swags. Reference frame 8s.
- **seal:** Transparent elongated scalloped blush rococo cartouche, thin double mauve/champagne line ornament, blank center for live C&A text. Reference frame 0s.
- **gate-paper:** Uniform grey olive-sage heavy stationery paper, very subtle vertical fibers, no border, folds, text, gradients or objects.
- **floral-frame:** Transparent tall champagne double-line frame, dusty roses, ivory flowers, sage foliage and hanging mauve wisteria around corners; large transparent live-text center. Reference frames 12s/16s.
- **swans:** Two ivory swans facing inward, heart-shaped necks, pale sage pond, rose and olive foliage base; fine engraved embossed watercolor style, transparent surround. Reference frame 12s.
- **story-arch:** Tall oval-topped botanical arch with slender sage leaves, dusty rose/ivory flowers and hanging mauve wisteria; open bottom, transparent live-text center. Reference frame 20s.
- **attire:** Five miniature full-length wedding guests in one row; two black tuxedos, three dusty rose/mauve/sage evening gowns; antique fashion watercolor, transparent surround. Reference frame 18s.
- **garland:** Wide shallow U-shaped sage foliage swag, layered ivory pearl beads and tiny roses, embossed antique watercolor, transparent surround. Reference frame 14s.
- **timeline-icons:** Five miniature engraved wedding motifs in equal columns: chapel, champagne, cutlery, cake, gold sparkler; transparent backdrop, no labels or grid.

## Typography / UI icons

Cormorant Garamond from `@fontsource/cormorant-garamond`, bundled locally. OFL license is included in the installed package and `public/licenses/`.
Standard map/calendar/replay/arrow controls use `@phosphor-icons/react` (MIT); license copied to `public/licenses/`.

New generated illustrations approximate the source style rather than reproducing identical original artwork. Original implementation technology is unknown.
